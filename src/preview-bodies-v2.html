TOMO // BODY CONCEPTS v2

Cel: czytelność z 2 metrów. Jedna silna sylwetka + glyph roli + kolor.
Zero „błota” z tysiąca znaków. Animacje tylko tam, gdzie niosą info (PULSE / SPIN / AIR).
01 — CLEAR BADGE
Gruby border + duży glyph na środku + lekki outer ring. PULSE scale-pulse, AIR dashed. Najprostsze i najbardziej czytelne.
-COLOR 03
% PULSE@ FOUND# COLOR+ TENS* AIR
+ MAX READABILITY+ SZYBKIE+ CZYTELNE ROLE
02 — HATCH DISK + SCAN
Hatch fill (jak meters/lattice) + biały glyph + scanline. Spójne z HUD TOMO, nadal czytelne dzięki grubemu borderowi i dużemu znakowi.
-FOUNDATION 02
HATCH = MASSGLYPH = ROLESCAN = LIVE
+ HUD DNA+ CZYTELNE+ LEKKI RUCH
03 — RETICLE / SCOPE
Celownik: 3 pierścienie + krzyż + badge z glyphem + conic sweep. Wygląda jak instrument pomiarowy. Size = średnica reticle.
-PULSE 01
RINGS = SIZESWEEP = ACTIVE
+ SCI-FI SCOPE+ BARDZO CZYTELNE+ POKAZUJE SIZE
04 — PIXEL SPRITE
Chunkowy pixel-circle (jak sprite z gry). Glyph nad sprajtem. Zero antialias — ostre, czytelne, CRT-native.
-TENSION 04
PIXEL GRIDNO BLUR
+ PIXEL DNA+ CZYTELNE+ SZYBKIE
05 — CORE + ORBIT DOTS
Kwadratowy core z glyphem + orbitujące kropki. Liczba kropek = GRAIN, kierunek = SPIN. Jedyne, które uczciwie pokazuje spin.
-TENSION 04
DOTS = GRAINDIR = SPIN
+ POKAZUJE SPIN/GRAIN+ INSTRUMENT+ CZYTELNY CORE
06 — SIGNAL NODES (SHAPE PER ROLE)
Różny kształt per rola, ale zawsze czytelny: PULSE=kółko, FOUND=bary w boxie, COLOR=kwadrat, TENSION=romb, AIR=dashed circle. Glyph zawsze duży.
-COLOR 03
SHAPE = ROLENO GUESSING
+ ROLE NA PIERWSZY RZUT+ CZYTELNE+ RÓŻNORODNE
